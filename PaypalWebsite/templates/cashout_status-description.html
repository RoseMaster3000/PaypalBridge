Cashout Button Status – Help & Information

This panel controls the behavior of the Cashout button inside Unity. The server can override the button’s state at any time, allowing you to disable or enable cashout functionality remotely.

The Cashout button has two independent controls:

  • Override — forces Unity to use the server‑defined state instead of local logic.
  • Interactable — determines whether the Cashout button is clickable or disabled (greyed out).

How Unity behaves:

  • If Override is OFF → Unity uses its normal logic (payout amount, gem count, errors, etc.).
  • If Override is ON → Unity ignores local logic and uses the server’s Interactable value.
  • If Interactable is OFF → Unity greys out the Cashout button and prevents clicking.

This system allows you to temporarily disable cashouts globally, perform maintenance, or prevent abuse without updating the app.
