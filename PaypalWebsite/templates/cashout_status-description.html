Cashout Button Status – Help & Information

This panel controls how the Cashout button behaves inside Unity. The server can override Unity’s normal gem‑based logic and enforce global maintenance or admin‑only testing mode without requiring an app update.

The Cashout system has two server‑side controls:

  • Override — when enabled, Unity ignores gem logic and follows server rules.
  • Admin‑Only Interactable — when Override is ON, this determines whether admins only can use the Cashout button.

How Unity behaves:

  • Override OFF → Unity uses normal gem logic (payout amount, gem count, login state, etc.).
  • Override ON + Admin‑Only Interactable OFF → Global Maintenance Mode: The Cashout button is always disabled for all users, and Unity shows a maintenance message.
  • Override ON + Admin‑Only Interactable ON → Admin‑Only Testing Mode: Admins follow gem logic normally; all non‑admins see maintenance and cannot cash out.

This system allows you to safely disable cashouts, run maintenance, or test payouts as an admin without affecting normal players.
