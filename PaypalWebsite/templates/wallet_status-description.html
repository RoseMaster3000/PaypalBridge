Age Restriction System – Help & Information

When the Age Restriction System is enabled, Unity will check the user's age against the minimum age you set here.

If the user is underage, Unity will:

  • Hide the Wallet access button
  • Hide the Counter access button
  • Hide the normal Login button and show the Age‑Safe Login instead

This blocks all access to wallet and cashout features because both the Wallet and Login buttons lead into the cashout flow.

If the user is not underage:

  • All buttons behave normally
  • The Age‑Safe Login button is hidden
