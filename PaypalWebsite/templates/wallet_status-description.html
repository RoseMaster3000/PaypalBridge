Age Restriction System – Help & Information

If Google Play implements age‑verification rules, this system will automatically hide all access to cash‑out features inside Unity when the user is under the minimum age.

Unity will hide the following three buttons:

  • Wallet access button
  • Counter access button
  • Login button that normally has access to the wallet (Unity will instead show the new login button without access to cashout)

Both checkboxes must be enabled for this behavior:

  1. Enable Age Restriction System — master switch that turns the entire system ON or OFF.
  2. Hide All Buttons When Underage — tells Unity to hide all three buttons for underage users.
